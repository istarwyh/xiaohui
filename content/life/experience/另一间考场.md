2026 年高考这天，我忽然想起，两年前的昨天，我从淘宝离职，来到蚂蚁。

后来我有点理解，考生们以为离开考场就是考试结束了，实际上推开公司大门会发现，人只是进了另一间考场。

生活中很多时候没有准考证，没有标准答案，也没有铃声告诉你该什么时候交卷。题目是一天天发下来的，有时是业务，有时是技术，有时是人心。那么这两年，又多了一个题目，叫 `AI`。

我花了一天时间，整理这两年来的一些足迹。记录一下，说明我曾经在考场坐过，也确实写过几道题。以后还有没有这样的机会呢，谁也不知道。

## 从 Java 到 Agent

刚入职蚂蚁时，因为做 `Agent`，我的 Java 老本行很快就拜拜了。

这件事多少有点荒诞。Java 是我过去几年最熟悉的工具，是我在业务系统里安身立命的老手艺。但 `AI` 浪潮来得太快，许多原本稳固的技术栈忽然显得笨重。不是它们没用，而是它们上船太晚。

那时我参与 [[Case Analysis AI Agent]]，用了 `AgentUniverse` 和 `PEER` 模式。到了年底，因为给 `AgentUniverse` 提了 [#202 PR](https://github.com/agentuniverse-ai/agentUniverse/pull/202)，我获得了蚂蚁开源轻训营-最佳贡献奖。那时我相信它会走得更远。

不久后，`AgentUniverse` 基本被 `LangGraph` 替代。

技术世界有一种近乎冷静的幽默：它不否认你的努力，只是转身很快。你写下的东西未必会成为历史，你只能尽量让它成为你的一部分。

## 想法需要有人持续付账

2025 年中，我带团队获得 OceanBase `AI` 黑客松二等奖，后来又拿到了蚂蚁黑客松三等奖。

感谢我的伙伴们。那时候大家一起想，一起写，一起熬，把一个想法从纸面上、从空气中拽出来，让它站在灯光下面。

只是可惜，项目终究没能一起走下去。

那也是我第一次具体地知道，做老板这件事情很难。想法本身不值钱，想法值钱需要有人持续地为想法付账。一个点子被说出来的那一刻，往往是它最轻盈的时候；真正沉重的是后来每天都要继续相信它、修补它、解释它、养活它。

## 分享不是把东西讲出去

2025 年下半年，我开始在更大的范围里分享 `AI Coding` 和 `Agent` 工程实践。

先是在阿里集团奇点学堂分享 `AI Coding` 工具与实战案例，主打 [[【万字长文】 最强 AI Coding：Claude Code 最佳实践|Claude Code 最佳实践]]。[AI Speeds](https://aispeeds.me) 最早也是为了分享 `Claude Code` 最佳实践而诞生的。

后来，我陆续在财富与保险事业群 HR 团队、蚂蚁保产品团队、蚂蚁保 `BI` 团队、钱塘征信、蚂蚁集团平台体验技术部智能工程技术团队，以及阿里国际 Accio 团队、ATH 心流团队等团队，分享 `Claude Code`、C 端 `AIGC`、`Agent` 上下文工程与 [[如何放心 100% AI 交付需求(3) -- 为 AI 打造可持续迭代的环境|Harness Engineering]]。

我觉得分享这件事，即使没有报酬也不会吃亏。

我以为自己在讲工具，其实是在讲一种新的工作和组织方式。以为自己在回答别人，回答着回答着，自己想得更清楚了。所幸，也确实帮到了一些同学。

2026 年 4 月，我获得财保 ACE「AI 先锋」荣誉。最近，我也首次跨公司，在平安健康险团队分享了 [[Harness Engineering: C 端 AIGC 实时生成系统|Harness Engineering]]。

这些事情放在一起看，好像是在证明我确实成长了。但将要去往何方呢？下一个项目能成功吗？我依然面对着巨大的迷茫。

## 手艺人

写到这里，我忽然想到《斯通纳》。斯通纳是个世俗意义上的失败者，不过在一战和二战的文明凋零时代，他始终坚守了自己的课堂和文学，坚守了自己的象牙塔。

我想我是一个手艺人。

不管技术潮水怎么转身，不管项目最后有没有站住，不管下一张试卷会不会突然发下来，我能做的，仍然是把事情做好、做明白。

也许这就是我在这间考场里能写下的答案。
