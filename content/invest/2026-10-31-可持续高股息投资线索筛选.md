我希望找到这样的公司：按今天的价格买入，即使生意没有预期中那么好，未来仍有余钱分给股东。最近把门槛设在税前 8%，再要求市盈率和市净率都低，筛出来的企业却横跨出版、租赁、电力、公路和综合控股。名单有了，判断才刚开始。

这套筛选思路受[思索的瓶起子](https://xueqiu.com/1088154788)启发。“两低一高”给了我一个寻找投资线索的入口。下面的具体阈值、现金流核验和每周扫描流程，是我结合自己的研究目标整理的版本，不代表原作者的完整方法或荐股意见。

我把它放进 [[agent-investing|Agent 投资系统]]，作为发现研究对象的一种方法。这里的 `source`，指值得继续查证的投资线索。

## 投资认知要落成可以检验的规则

这套方法目前属于量化筛选加基本面判断。市盈率、市净率的门槛可以重复执行；“分红是否可持续”仍依赖对付款人、必要投入和经营情景的研究。买多少、何时调仓、什么条件下卖出还没有完整规定，因此它还不是一套经过验证的量化交易策略。

我要求以后博客里的投资认知，都继续落成可以量化、执行和复查的规则。说一家公司“有护城河”“现金流健康”“受益于债权循环”，必须进一步指出观察什么、怎么计算、在什么条件下改变判断，以及判断会怎样影响行动。

**如果一条认知始终落不成这些规则，我会认为自己对它的理解还不够，研究也还不够科学。** 它可以作为待验证的假说保留，但不能凭一句“我理解这门生意”，就获得指挥仓位的资格。

例如，“客户付款能力变差”要继续落到应收账款账龄、回款周期、客户收入和债务到期情况；“分红有保障”要写出必要投入后的现金覆盖、压力情景下的每股股息，以及不足时转入观察或剔除的条件。具体阈值要有行业和历史依据，不能为了让某只股票通过而临时调整。

有些判断暂时只能分类，或者只能给出区间。那就写清分类依据、估算上下界和证据缺口；缺资料时允许规则输出“暂不判断”。把模糊认识强行压成一个小数点后两位的分数，只会隐藏我们还没弄懂的部分。

规则写出来以后，还要接受检验。使用当时已经公开的信息，保留退市和失败样本，计入交易成本，用较早的数据制定规则，用之后未参与调参的数据检验，并跟踪实际结果。回测中不断调门槛直到收益好看，不能证明这条认知成立。若规则用于交易，还要检查它是否优于简单基准，以及收益是否只是承担了更多风险。每次修改规则，都要留下旧版本和修改理由，不能事后改写过去的判断。

`Agent` 要把文章里的主张拆成数据字段、计算口径、行动条件和反证，标出尚未落实的部分；无法落实的，继续研究，不能自动生成买卖指令。

## 先用数字缩小范围

当前这轮研究限定 A 股和港股，初筛条件是正市盈率 `PE ≤ 8`、市净率 `PB ≤ 0.8`，再检查保守估计的未来普通现金股息率能否达到 8%。

这三个数是我设的研究门槛。它们会偏向成熟、资产较重、增长预期较低的企业，也会漏掉不少好公司。净资产还要检查应收款、商誉和资产减值；账面上打八折，未必比可收回的价值便宜。

低估值和高股息还会同时被股价下跌“制造”出来。股价跌一半，利润、净资产和过去分红尚未变化时，市盈率、市净率都会减半，历史股息率则翻倍。三个指标一起变漂亮，未必增加了三份独立证据。

同一口径下，股息率约等于派息率除以市盈率。一家公司市盈率 5 倍、派息率 40%，对应股息率就是 8%。接下来真正需要验证的是，利润能否留下来，以及公司能否继续拿出其中的 40%。

每个数字旁边都要留下行情日期和计算依据。滚动十二个月市盈率用 `TTM` 标记；年度利润、滚动利润和预测利润不能混着比较。港股价格若用港币，每股股息就要换成同一币种，注明汇率或实际派付币种。

## 那个 8%，究竟是哪一年的钱

行情软件上的高股息率通常来自历史分红。过去派过，不等于现在买入还能收到；去年有钱分，也不等于明年有钱分。

我会把普通分红、特别股息和未来预计分红分开。已经除息的分红不计入新买入者未来可领取的现金；卖资产派出的一大笔特别股息，也不直接续到下一年。已宣布但尚未除息的分红，则核对资格日期与派付日期。

> 以当前可核实价格买入，保守估计未来 12 个月可领取的普通现金股息税前收益率不低于 8%，并检查未来两三年的支撑条件。

8% 是情景估计，不是公司欠我的利息。税后到账还受持有渠道、税务身份、汇率和费用影响；股价损失也可能超过收到的股息。

## 把财报放回生意里

**这家公司靠什么持续收钱？** 谁付钱、为什么付、有没有替代选择，决定了收入能持续多久。教材发行要看学生数量、采购安排和发行资格；公路收费要看车流、收费规则和剩余收费期限；电力收入要看电量、电价与结算；租赁利息要看客户能否还款。只写“行业龙头”无法回答这些问题。

**维持这门生意要再投入多少钱？** 设备会老，公路要修，回款可能拖延。折旧是会计费用，不能直接当作未来维护支出。资本开支也要区分维持现有经营与扩张，不过已经承诺、无法轻易取消的扩张项目仍会占用分红资金。财报没有拆分时，我会用总资本开支作更保守的参照，说明局限，不把缺失项填成零。

**剩下的钱能否稳定分给股东？** 公司要先满足必要投入、债务偿付、资本要求和现金储备，还要有分红意愿与实际可分配利润。子公司的现金未必都能上划，合并报表里的钱也不全属于母公司普通股股东。

对于一般非金融企业，我从经营现金流减资本开支开始核对，再处理租赁本金、尚未计入的利息和必要偿债，排除不可持续的回款改善。经营现金流已包含营运资金变动，不能机械再扣一遍。利息是否已经扣过，也必须查看公司采用的现金流列报口径。[现金流准则资料](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)能帮助理解分类，但具体计算仍以该公司财报及附注为准。

银行和租赁公司另算。放贷会消耗现金，收缩贷款会释放现金，经营现金流的正负不能直接判定分红质量。我更看重资产质量、核销与拨备、资本缓冲、融资成本和期限错配。不良率下降时，还要检查是否伴随更多核销，不能只看比例。

过去至少三年的盈利、现金流和分红一起看，必要时延伸到完整行业周期。单期现金流变好，可能只是集中收到补贴、减少采购或延后付款；这些都不适合直接外推。

## 沿着分红往上追，谁在付款

在 [[债权经济学#一笔开支，就是另一笔收入]] 里，收入总能追到另一方的支出。一笔分红是股东的收入，也先是公司的现金支出。公司的现金来自客户，客户的钱又来自工资、经营收入、财政预算或融资。只看到上市公司账户上的余额，链条还没查完。

[[债权经济学投资框架]] 里的“最终甲方”和“债务能否自偿”，正好补上这一层。这里借用的是追踪付款和偿债关系的视角；股票在法律与会计上是权益，普通股分红不因此变成债权人的固定请求权。

假设一家公用事业企业按时确认收入，但地方客户付款越来越慢。利润还在，应收账款却越积越多。它若一边借短债维持分红，一边等待客户回款，漂亮的股息率就依赖两件事同时成立——客户最终付得起，银行愿意继续借。研究要追到客户的财政收入、收费来源和债务到期安排，不能停在“有政府背景”。

租赁公司也类似。它收到的利息来自承租人的现金流。如果承租人用设备提供服务、卖出产品，经营收入能覆盖租金，分红就有真实业务支撑；若承租人只能继续借钱付租金，风险会沿着租金、信用损失、利润一路传到股息。

负债本身不是否决项。长期资产需要匹配长期融资，合理续借也可以是正常经营的一部分。我要区分的是，融资有没有对应能产生现金的资产，资产回款和债务到期是否匹配，以及融资收紧时谁先承担损失。即使企业暂时靠延迟支付供应商保住现金，也不能把这当作永久提高了分红能力。

这让每家候选多留一条记录：最终付款人是谁，他的钱从哪里来，若他的收入下降或借不到新钱，多久会影响上市公司的回款和分红。指标筛选可以先执行，但研究判断上，付款来源比便宜的倍数更靠前。

## 给“保守”写出具体数字

保守情景要落到生意变量上。电力企业可以检验电价下降，资源企业要把商品价格从高位往回调，金融企业要增加信用成本并检查融资压力。不能给所有行业统一打九折，再给结果贴上“保守”的标签。

下面只用一组假设数字说明计算，不对应任何真实公司。假设公司有 10 亿股，全部金额使用同一种货币：

| 项目 | 假设值 |
| --- | ---: |
| 当前股价 | 5 元 |
| 去年每股普通股息 | 0.50 元 |
| 历史股息率 | 10% |
| 压力情景下扣除必要投入、偿债和现金储备后，母公司可用于普通股分红的现金余量 | 4.2 亿元 |
| 同期可分配利润与分红政策能够支持的普通分红 | 3.6 亿元 |
| 采用的保守分红总额 | 3.6 亿元 |
| 保守每股股息 | 0.36 元 |
| 当前价格对应的保守股息率 | 7.2% |

这里假定 3.6 亿元能够在未来 12 个月派付，且新买入者有领取资格。历史上看起来有 10%，保守估计只剩 7.2%，按这轮规则就不能入选。

倒过来算，0.36 ÷ 8% = 4.50 元。这是该分红假设下满足目标股息率的价格上限，不是公司的内在价值，也不是自动买入价。股价跌到 4.50 元时，必须重新确认导致下跌的消息有没有推翻 0.36 元的估计。

## 让每周扫描留下可以复查的东西

每周扫描覆盖 A 股和港股，行情数据负责发现线索，交易所公告和公司财报负责验证。输出最多五家；没有严格达标的，就写没有。

| 记录 | 要能回答的问题 |
| --- | --- |
| 行情日期、币种、估值口径 | 这个价格和这份利润是否匹配？ |
| 财报与分红公告链接 | 数字来自哪份文件、哪个期间？ |
| 最终付款人与资金来源 | 收入或融资收缩会从哪里传过来？ |
| 收钱方式与必要投入 | 哪项经营变化会先影响分红？ |
| 保守情景及每股股息区间 | 假设变差后，还能分多少？ |
| 8% 对应价格上限 | 在什么价格条件下值得继续研究？ |
| 反证与退出观察条件 | 什么事实会推翻当前判断？ |
| 相对上次的变化 | 是价格变了，还是生意变了？ |

证据不足的进观察名单，普通股息不足的剔除，不能用特别股息补齐门槛。不同公司若共同依赖信用扩张、地产需求或商品价格，也不能因为行业名称不同就当作充分分散。

`Agent` 可以找公告、对数字、追踪变化，但研究记录必须把已披露事实和估算分开。每次复查都保留旧假设，在 [[个人投资的七步迭代框架]] 中记录哪些事实推翻了上次判断。

没有达标标的时，每周报告就写没有。过去分过不少钱，还不足以支持我按今天的价格买入。
