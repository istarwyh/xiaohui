# 文章分享图

分享面板保留「二维码短卡」，并提供「长文分享图」。两种版式共用预览、保存图片、系统图片分享和不支持系统分享时的保存回退。默认仍是短卡。

## 内容与版式契约

- 短卡沿用标题与短描述，长图读取当前文章正文的真实 DOM，按原文顺序呈现，不使用 description 代替正文，也不自动生成摘要。
- 文章标题与晓灰站点标识始终保留。署名只来自文章已有的 `frontmatter.author`，支持字符串或字符串数组；不把 SEO 元数据里的站点名后备值当作作者。
- 长图保留段落、小标题、列表、引用和代码的基本结构。内容适配画布高度，约 800 字是自然内容块收尾的参考，不要求在固定字符处截断。额外的高度保护用于极长段落、代码和特殊内容。
- 未展示完时，渐隐只覆盖正文结尾，并附继续阅读提示。下方独立的二维码、阅读全文提示及站点信息保持清晰，二维码指向当前页面 canonical URL。
- PNG 在浏览器本地生成，不上传正文。颜色、字体取自 `quartz/design/tokens.ts`；导出采用浅色纸感，便于跨应用阅读。代码用等宽字体；正文用 CJK 友好字体。
- 预览按面板宽度展示，长图通过面板纵向滚动阅读，不把整张长图缩进一个固定高度的小框。

## 生命周期与回退

- 每种版式独立缓存，一篇文章最多保留两张图片；重复选择复用结果。
- 切换版式、关闭或重新打开面板、触发新操作后，较早的异步完成不能覆盖当前预览、状态或触发迟到的下载。
- 生成失败不会永久缓存失败结果，保存或切换版式可以重试；复制链接始终可用。
- 只有已缓存的图片可在用户点击的同步激活期间尝试系统分享。生成尚未完成、系统不支持、微信内浏览器或系统分享失败时，显示图片供保存或长按。取消系统分享不视为成功。
- SPA 离开文章时清理监听器、面板与对象 URL。离开后才完成的图片也立即释放。

## 验证

自动测试通过 `npm test` 执行，包括长图内容与排版边界、实际 SSR 署名和真实 inline 脚本的异步生命周期。设计契约与类型/格式检查仍使用 `npm run check:design` 和 `npm run check`。

`npm run test:share-browser` 使用 Chromium 对真实组件执行浏览器验收，解码导出的 PNG 二维码并保存 320px / 390px / 桌面截图。首次运行需要 `npx playwright install --with-deps chromium` 和可显示中文的字体。CI 在独立只读 Ubuntu 作业运行这些测试并上传 `share-posters-<SHA>` 证据，不部署网站。详情见 [浏览器测试说明](../tests/browser/README.md)。

真实浏览器还应检查：

1. 短文、接近阈值、超长文章与超长单段，中文与混合文本。
2. 小标题、嵌套列表、引用、代码与特殊内容无重叠、溢出或字符裁切。
3. 320px、390px 和桌面面板；浅色和深色页面上的预览与键盘焦点。
4. 两种图片的保存、系统分享/取消与不支持时的回退。
5. 反复切换、关闭重开、生成失败后重试和 SPA 离开。
6. 实际导出 PNG 的正文可读性、清晰的阅读全文区域，以及二维码解码结果等于 canonical URL。

## 真实项目内容复验

浏览器集成测试可通过 `SHARE_QA_SITE_DIRECTORY`、`SHARE_QA_ARTICLE_PATH` 和
`SHARE_QA_ARTICLE_TITLE` 指定新构建的真实文章。CI 另构建原有 content vault，
使用《DDD》验证真实正文、移动端预览、保存下载及完整 canonical URL 的二维码。
中文 canonical 的预期值通过标准 URL 解析规范化，不把 URI 与百分号编码的等价表示
误报为二维码指向不同地址。包含 Mermaid 的文章使用生产配置中的官方 CDN SDK 字节；
测试不以空脚本或伪造 Mermaid 实现代替实际运行。

真实《DDD》PNG 已视觉检查段落、小标题、列表、引用、自然收尾与渐隐、独立二维码。
这不覆盖全部文章，也不改变现有 Canvas 的简化边界：行内强调、图片、公式和表格
的原版式仍未完整保留，真实 OS 分享面板仍待实机验证。当前实现保持 draft。
