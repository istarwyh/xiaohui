# 晓灰品牌资料页与资源

公开入口 `/brand`。这是品牌参考页，不是文章；不会进入 feed、RSS、文章搜索或 Agent 文章索引。全站页脚有“品牌资料”入口。

## 设计与来源

资料结构参考 [AI Speeds 品牌资料](https://aispeeds.me/brand)：标识预览、下载、配色与排版、引用示例和使用说明。标识、路径、配色和说明为晓灰项目重新设计，未复用参考站点的山峰标识、渐变或品牌文案。

本次图形由晨光与打开的两页笔记组成，结合“晓灰”和博客已有“写代码也写字”的表达。字标仅使用“晓灰 / XIAOHUI”；不新增履历、头衔、成就、认证或合作关系。现有 favicon、首页名称与作者文案不因此替换。

## 单一来源

- `quartz/design/tokens.ts`：亮暗颜色、字体、尺寸和纹理 token
- `quartz/design/paperTexture.ts`：192px 静态平铺纸张纹理，SVG 小于 1KB
- `quartz/design/brandAssets.ts`：原创图形和已转路径的字标，颜色直接来自 token
- `quartz/components/BrandKit.tsx`：页面、资源列表、色值和引用示例
- `quartz/plugins/emitters/brandPage.tsx`：构建时生成页面、SVG、PNG、配色 JSON 和 TXT 说明

不要手工编辑 `public/brand*`，也不要复制一份品牌颜色到组件。PNG 由同一 SVG 构建生成，JSON 从同一配色对象导出。构建遇到 authored content 占用 `/brand` 或 `/brand/*` 时会报错，避免静默覆盖文章。

## 输出文件

| 文件                           | 用途                         |
| ------------------------------ | ---------------------------- |
| `xiaohui-mark.svg`             | 浅底独立图形，64×64 原始画板 |
| `xiaohui-horizontal-light.svg` | 浅底墨色横向组合，224×96     |
| `xiaohui-horizontal-dark.svg`  | 深底浅色横向组合，224×96     |
| `xiaohui-monochrome.svg`       | 单色图形，内联可设置 color   |
| `xiaohui-mark.png`             | 512px 透明 PNG               |
| `xiaohui-horizontal-light.png` | 1200px 宽透明 PNG            |
| `xiaohui-social.png`           | 1200×630 浅纸底介绍封面      |
| `paper-light.svg`              | 静态纸面纹理                 |
| `palette.json`                 | 同源亮暗颜色与字体栈         |

SVG 不嵌入字体、脚本、外部图片或运行时依赖。字形轮廓基于 Noto Sans CJK SC Bold / Regular（SIL OFL 1.1），只保留展示字形的路径，不分发字体文件。

## 使用契约

- 图形建议至少 32px，横向组合建议至少 224px；保持原始比例、画板留白和至少高度 1/4 的外侧留白
- 浅底使用墨色版，深底使用浅色版；不要拉伸、挤压、重绘、添加光晕或额外渐变
- 单色 SVG 的 currentColor 只在内联使用时继承页面颜色；`img` 引用保留其默认墨色。通过 `img` 使用时优先选择固定浅/深配色版本
- 下载链接带 `download` 和 `data-router-ignore`，避免 SPA 把文件当作文章页面处理
- 复制按钮只在用户点击时写入剪贴板，有明确成功提示和失败后手动复制说明
- 使用标识应准确说明来源与作者，不制造未经确认的合作、认证或推荐印象

## 纸张纹理与可访问性

亮色纸面提亮、减黄；正文前景保持原本的可读层级。纹理作为背景图片绘制，不使用覆盖文字的伪元素、Canvas、动画或混合滤镜。

亮色纹理最大不透明度 4.5%，暗色 1.8%。测试会计算最坏纹理像素与所有支持表面的合成颜色，正常文字仍不低于 4.5:1。高对比度、强制颜色与打印模式关闭纹理。减少动画模式无需额外运行，纹理本身始终静止。

## 验证

`npm run check:design` 包含 token、品牌页面与资源检查，并接入 `npm test` / CI：

- 原始颜色、未定义变量与字体漂移检查
- 纹理体积、安全性与最坏合成对比度
- 下载文件名、尺寸、可访问名称和无外部依赖
- 所有 SVG 使用 sharp 真实栅格化，检查透明边缘与未裁切图形
- 页面引用文件、下载绕过 SPA、同源配色和复制失败提示

最后仍需在实际预览核验亮暗、窄屏、纸纹可读性、跳转/复制和真实下载文件。保持原有紧凑 feed 契约，品牌页不能改变文章密度。

## 独立展页的构图

`/brand` 使用自己的页面节奏：大字身份首屏、晨光书页展台、亮暗成对样本、带实物预览的资源画廊、大面积可复制色样、双字体样张和引用面板。参考 AI Speeds 的独立页面层级与可用资源组织，而非套用博客文章的连续清单。

大字号、展板圆角和展示间距只定义在 `brandKit.scss` 的 `.brand-*` 组件中。页面外壳覆盖仅作用于 `body[data-slug="brand"]`，不修改全站 token、首页、feed、文章或 Quartz 默认布局。所有标识文件与颜色继续读取原有单一来源；亮/暗样本固定其展示底色，以便同时比较，不随页面主题误用版本。首屏装饰线是静态 CSS 图形，不是新标识资产。

页面导航保持原生锚点；所有十个下载项保留独立名称与 SPA 绕过属性。排版示例也有可链接的 `#brand-type` 目标。渲染测试检查真实组件的单一 h1、唯一 ID、有效锚点、十个下载与十一处复制入口，补充原有源码契约测试。

### 预览反馈：文章的两个局部修正

品牌页预览后，针对 `/journey` 截图中暴露的阅读问题，额外修正文章模板：正文保留 `44rem` 阅读行宽，但与标题左对齐，避免居中产生额外左侧缩进；文章标签移至正文后、底部面包屑前。首页与 feed 的布局、密度和内容保持不变。此处不是博客的整体改版。
