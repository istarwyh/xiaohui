# 公开只读工具启用

2026-11-02，站点所有者明确要求 WebMCP 保持开启，取代此前分阶段交付时的默认关闭策略。PR #120 的数据访问、三个只读工具和模块隔离保持不变。

- 构建环境未设置 `QUARTZ_ENABLE_WEBMCP` 时默认包含工具；设置 `1` 显式启用，设置 `0` 显式关闭。空值或其他值不启用。
- `.env.example` 只是示例，不会自动设置构建环境。若部署平台仍显式设置 `0`，该设置仍有效；发布验收必须读取实际产物，不能只看源码默认值。
- 注册仍要求安全上下文及浏览器提供 `document.modelContext.registerTool`。不支持的浏览器静默降级，普通搜索、文章阅读与 llms 入口继续可用。不注入 polyfill、不增加跨域权限、不读取私人数据。
- `search-notes`、`read-note`、`get-current-note` 仅访问已公开文章；不会新增写操作。

## 验证边界

开启产物和关闭产物分别检查；测试默认值、显式开关、不支持宿主、部分注册失败清理、SPA 生命周期以及实际公开内容的搜索/正文读取。

正式部署后核实发布 SHA、部署产物版本和工具注册。若现场浏览器没有原生 API，记录这一能力限制，并使用模拟宿主和实际生产公开数据验证协议/数据链路；这种替代证据不是实际 Agent 端到端成功。

原生 Chrome/Origin Trial、每个真实 Agent 产品和移动性能的完整支持矩阵仍需逐项验证；不能据默认开启承诺所有浏览器或 Agent 均可发现工具。此前 01–06 文档中的“默认关闭”描述是阶段性历史记录，以本次启用策略为准。
