# 首页编辑布局实施

基线为 PR #97 合并提交 `97d0800f38bdc1f2c048c0f069ada1c4f86d4989`。实现延续 [首页方案 PR #96](https://github.com/istarwyh/xiaohui/pull/96)，不合并该文档分支，也不进行 Workers 迁移。

## 实际范围

- 专用首页 renderer variant；导航位于 main 外，主页不输出文章左右栏、图谱或拖柄。文章、品牌页继续使用已有布局
- 作者与既有工程背景 → 三项真实精选 → 三条阅读路径 → 单份最近更新文章流 → 关于与交流
- 中文精选为可靠 Agent 系统、RAG 到 Deep Research、Agent 投资系统；英文使用已有翻译，投资阅读路径标注中文
- 默认遵循现有标题与作者文案，没有新增履历、收益、成效或服务承诺
- 首页正文保留在 Markdown 中供 legacy 回滚，editorial 不重复渲染；既有中文 Userdesk/Clarity 服务迁入资源脚本并去重，未新增供应商或账户
- feed 按当前语言过滤，日期统一为 modified → published → created，保留至多三张真实128×96缩略图与既有行密度
- 无JS仍显示全部静态文章；正常增强后首批10篇，显式按钮继续加载、移动焦点、播报数量，并恢复 Back 可见数量与阅读位置
- 搜索使用唯一实例，补齐加载/失败状态、关闭按钮、IME、焦点循环、字面量查询、高速连续输入与预览竞态保护
- docs/index 没有显式标记，因此仍渲染文档正文；主页增量构建依赖所有已发布文章和资产的新增/更新/删除
- 保留 PR #97 的文章标签下移、正文对齐及品牌布局，补上品牌规则序号不换行

## 四类模拟用户验收

### 首次访客

- 实际首屏能够说明作者、主题与已有工程背景
- “开始阅读”到精选、首篇精选到文章、Back 返回精选、搜索再次打开、关于我页面均通过
- 最终像素复核通过，卡片内边距与纸白表面、wordmark 已脱离上游 internal-link 样式干扰
- 所有身份与精选文案均来自仓库已有作者内容；投资系统明确为建设中

### 技术读者

- 中文搜索“上下文工程”有 8 条结果，ArrowDown 选中第一条，Enter 打开 OneAgent 文章；返回后可再次搜索
- 切换英文后搜索、Enter 打开 Deep Research、Back、Engineering & Agents 路径、返回中文均通过
- 多次往返后搜索与主题工具仍存在且可使用；新首页不搬移搜索 DOM
- 英文文章原有日期/阅读时长仍使用全局中文 UI locale，属于未扩展修改的既有文章元信息范围

### 回访与 RSS 读者

- 中文连续 10 → 20 → 30 篇，进入文章再 Back 仍为 30，继续加载到 40 通过
- 英文 10/16 → 全部 16；回到中文后 40/547 保持，两个路径状态独立
- RSS 说明页可访问；浏览器 XML 显示受限，没有据此推断站点故障
- 对同一预览的 `GET /index.xml` 使用普通 HTTP 客户端实际检查：HTTP 200、`application/xml`、643,238 bytes；XML 解析为有效 rss/channel，20 个条目全部含标题与 canonical 文章链接
- 静态产物包含 547 个中文和 16 个英文文章入口，无初始隐藏卡片，没有重复的 latest-six 区块

### 移动端与键盘

中文首页在 320、390、768、800、1024、1200、1440 CSS px 的浅色与深色均实际观察，可见内容无横向越界；801 切换桌面导航/三列，1201 边界也稳定。

- 搜索 Shift+Tab 闭环、Escape、重复打开，以及加载更多焦点与数量通过
- 最多三张真实缩略图；320 时约 85.9×64.4 CSS px，保持 contain，不放大或横向裁切
- Article → Back/Forward 后展开数量与工具栏保留
- 英文首页 320/390 CSS px、200% 页面缩放的浅深主题补测通过：长标题换行、菜单内语言/RSS 入口、英文日期和全部 16 篇加载正常，无可见横向越界。英文 feed 没有图片，因此没有英文三图真实样本；共享缩略图布局的中文三图样本已测，不把无样本项写成通过

## 已知非阻塞项与未测范围

1. **P3：Back 后位置有约 54 CSS px 漂移。** 两名独立验收者记录同一锚卡 `-3.36 → 50.64` 与 `110.55 → 164.55`，仍在同一文章/阅读区，展开数量及继续加载正确。不是刻意设计；可能与原生滚动恢复或后续重排时序相关，原因未确证。不宣称像素级位置恢复，本轮不扩大为滚动体系重写。
2. **日期时区沿用既有规则。** 两个 `2026-09-24T00:00:00+08:00` frontmatter 时间在 UTC 构建中显示 9 月 23 日，与旧 feed 一致；没有静默修改全站日期时区政策。
3. **浏览器受限状态未实测。** 组织策略禁用 DevTools，因此没有执行实际 JavaScript-disabled、reduced-motion、forced-colors 或文字单独放大 200% 的浏览器模式测试。无 JS 静态链接与渐进增强失败回退有 SSR/脚本测试，但不冒充实际禁用 JS 的像素验收；浏览器 200% 缩放不等同文字单独放大。
4. **设备与性能边界。** 未在实体 iOS/Android、Safari 或其他浏览器引擎测试。没有采集真实流量 p75 LCP/INP/CLS，也没有三次冷启动实验室中位数；不提供推算的性能分数或把 TBT 当成 INP。

## 体积预算实测

同一 Linux/Node 24 环境、本地完整生产构建，与 PR #97 最终本地产物比较；下表为 `gzip.compress(..., mtime=0)` 的 bytes，不代表 CDN 实际 Brotli 传输量。

| 产物          | PR #97 gzip | c37c399 gzip |     差值 |
| ------------- | ----------: | -----------: | -------: |
| index.css     |      15,404 |       16,936 |   +1,532 |
| prescript.js  |         910 |          910 |        0 |
| postscript.js |     380,667 |      382,510 |   +1,843 |
| 中文首页 HTML |     115,550 |      109,005 |   −6,545 |
| 英文首页 HTML |     114,326 |       10,567 | −103,759 |

CSS 增量低于方案 8KB gzip、JS 增量低于 10KB gzip 预算。首屏复用内联品牌 SVG，没有新增首屏媒体请求。英文 HTML 明显减少主要来自按语言筛选 feed。共享 bundle 仍含文章页图谱等既有资源，没有声称首页“零图谱 JS”；随机构建版本可能使 HTML gzip 有几 bytes 波动。

## 资源缓存与首次升级

每次构建的 CSS、prescript、postscript 与 contentIndex URL 带同一个构建版本，页面 head 也输出版本。已运行新版客户端遇到其他版本的HTML时，在更新DOM前进行完整导航，避免旧JS处理新结构。正常同版本导航继续使用SPA。

首次部署时，已经打开的旧客户端没有版本检查逻辑，仍需要普通刷新一次才能获得新客户端。无需清缓存或硬刷新；这是既存运行代码的升级边界，不声称版本参数能追溯修复已经加载的旧JS。后续发布由版本检查保护。

## 回滚

重新构建时设置 `QUARTZ_HOME_LAYOUT=legacy` 可恢复原首页组合；首页明确标记仍保留。也可在得到发布授权后 revert 本实现PR。两者都不回滚PR #93/#95/#97的紧凑feed、设计token、品牌及文章修复。

`npm run build` 不再调用过时的CardFeed/Unsplash生成器；显式执行旧命令遇到 `pageType: home` 会退出，不因 FORCE 覆盖首页或生成无用图片数据。
